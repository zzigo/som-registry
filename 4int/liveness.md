# Liveness

Croft (2007:65) defines liveness as the condition in which "the relationship between a performer's actions and the resulting sound" is transparent to the audience. This is not the same as being live in the temporal sense (the performance happening now) but a qualitative property of the performer-instrument system.

Auslander (2008) frames the same idea as "perceived effort": instrumentality requires that the audience see the musician performing visible, effortful actions that map credibly to the acoustic result. The instrument must appear to be the mediating cause, not merely the backdrop.

Hardjowirogo (2017:16) treats liveness as a criterion of instrumentality: a system that produces sound without legible causal action — however sophisticated — fails to read as a musical instrument. This is why laptop performance provokes persistent debates about instrumentality: the mapping from hand movement to sound is hidden inside the machine.

Liveness is distinct from mediality: mediality is about the performer's phenomenological fusion with the instrument; liveness is about the audience's epistemological access to the causal chain.
