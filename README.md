# soog

Registry of the Speculative Organology model: one note per node, with YAML frontmatter that follows the schema kept in `03-som` (private).

- `1mat`, `2obj`, `3agn`, `4int`, `5env`: facet classes of MOAIE.
- `0ins`: instruments, as tuples of the five facets. Traditional, contemporary and fictional instruments in one place.
- `0-dict`: dictionary of terms.
- `soog-templates`: note templates.
- `.github/workflows`: notifies the musiki content bus when `0ins/` changes.

The repository began as the merge of the vault folder `03-soog` and the former `zzigo/soog-instruments`.
